# Edwin Jordan Herbas

Cofundador de **[NeumorStudio](https://www.neumorstudio.com)**, en Sevilla. Montamos el software que un negocio todavía hace a mano: reservas, gestión, captación de clientes y atención automática. Trabajo con agentes de IA en todo el proceso, del panel al vídeo que lo explica.

## En qué ando

- **[motion-skills](https://github.com/EdwinJordanHerbas/motion-skills)**: skills gratis para que tu IA haga vídeos demo y anuncios verticales con Remotion y three.js. Mejoran con las lecciones de quien las usa.
- **[Salonio](https://github.com/NeumorStudio/elbooksykiller)**: reservas para peluquerías y barberías, con la web de cada salón y su panel de gestión. En piloto.
- **[Vigía](https://github.com/NeumorStudio/vigia)**: comprueba las webs de los clientes y abre una incidencia si una falla.
- **[OkiroSport](https://github.com/EdwinJordanHerbas/starkos-pwa)** y **[TutorInglés](https://github.com/EdwinJordanHerbas/tutoringles)**: mis apps web para entrenar y para aprender idiomas.
